# trinity-design-system
Design system component library with a Storybook site deployed via GitHub Pages

## Run locally
```bash
npm install
npm run storybook        # http://localhost:6006
npx vitest --project=storybook --run --fileParallelism=false --testTimeout=90000   # WCAG 2.2 AA checks
```

## Publish Storybook (GitHub Pages)
Pushes to `main` build Storybook (`npm run build-storybook`) and deploy it via `.github/workflows/deploy-storybook.yml`.

One-time setup: repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
The site is then at https://codevictim.github.io/trinity-design-system/

## What's here
- `tokens/1-primitives/` — Brand Colors + Primitives (generated by `scripts/build-primitives.mjs` from `tokens/source/figma-primitives.json`)
- `tokens/2-style-layout/` — Style (Light/Dark) + Layout tokens used by the components (from `tokens/source/figma-style-layout.json`)
- `src/foundation/` — Colors, Typography, Spacing, Shadows pages
- `src/components/atoms/` — Icon, Spinner, Badge, _checkboxInput
- `src/components/molecules/` — Checkbox, Button (built from the atoms)

Source of truth: Figma "Trinity Design System (for review)". Token files are read-only pulls. Don't edit the generated CSS by hand.

Fonts (ABC Repro, TrinityIcons, TrinityBrandIcons) are licensed and must be installed locally. They are not in this repo.
