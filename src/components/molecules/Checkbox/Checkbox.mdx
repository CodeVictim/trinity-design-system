# Checkbox

A native checkbox with a label, for choosing one or more independent options. Built from the **_checkboxInput** atom. Figma: *Checkbox* `30515:78521`, 12 authored variants.

## Dependencies

- **_checkboxInput** (atom): the 24×24 touch area, the box, and the check / dash.

## When to use

- Independent yes/no choices, including in a list where any number can be chosen.
- A single opt-in ("I agree to the terms").
- A "select all" parent over a list, using indeterminate when only some are chosen.

## When not to use

<SimpleTable head={['Situation', 'Use instead']} rows={[
  ['Only one option can be chosen', 'Radio group'],
  ['The change takes effect immediately (a setting)', 'Toggle'],

## Accessibility

**Built in (the component handles it)**
- Role: native `<input type="checkbox">` inside a `<label>`, so clicking the text toggles it and the label is the name.
- States: checked / unchecked / mixed (`indeterminate` is set on the native input) / disabled. Screen readers get these from the browser.
- Hidden from AT: the drawn box (`_checkboxInput`) is `aria-hidden`; the real input is invisible but sits over the 24×24 touch area.

### Focus

- Indicator: 2px outer ring (`--checkbox-focus-outer-stroke`) plus a 1px inner stroke, shown on `:focus-visible`.
- Ring vs page: 15.61:1 (Light) / 21:1 (Dark).

## Usage guidelines

**Do**
- Phrase labels positively ("Send me updates", not "Don't send me updates").
- Stack checkboxes vertically, one per line.
- Use indeterminate only on a parent that controls a list.

**Don't**
- Don't use a checkbox to trigger an immediate action. Use a toggle or button.
- Don't hide the label unless the context makes it obvious (e.g. table row selection), and even then keep `label` as the accessible name.

## Content guidelines

- Labels: sentence case, no trailing punctuation, and they should make sense on their own.
- Group legends say what the group is for ("Notify me by").
