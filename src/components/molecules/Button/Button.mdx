# Button

A native `<button>` that starts an action. Built from the **Icon** and **Spinner** atoms. Figma: *Button* `30033:78562`, 144 authored variants (6 variants × 4 sizes × default / hover / focus / active / disabled / loading).

<InfoCallout>Accessibility pattern: <b>actions-buttons</b> (Storybook A11y Library). Target: WCAG 2.2 AA.</InfoCallout>

## Dependencies

- **Icon** (atom): prefix and suffix icons — size Small (16px) on xlarge / large / medium, **XSmall (12px) on small**, as authored.
- **Spinner** (atom): loading state. 16px for small/medium, 24px for large/xlarge.

## Accessibility

**Built in (the component handles it)**
- Role: native `<button type="button">`. Pass `type="submit"` inside forms.
- Name: the visible label (`children`). Icons are decorative (`aria-hidden`), so they're never read twice.
- Disabled: native `disabled`. It's removed from the tab order, so don't put essential information only in a disabled button.
- Loading: keeps its accessible name, sets `aria-busy="true"` and `aria-disabled="true"`, and ignores clicks. The spinner is hidden from screen readers. (Figma's prototype lets a loading button hover back to active; the code deliberately doesn't.)
- Focus: shows only for keyboard (`:focus-visible`), never removed.

### Focus

- Indicator: inner stroke + a 2px outer ring (`--border-focus`), different for each variant. Measured against the page background, every ring is **≥ 3:1** (lowest: destructive in Dark, 3.89:1).
- **Link** uses a thinner indicator: a 1px inner stroke and a 1px outer ring (Figma, updated 2026-10-20). The ring is 11.87:1 against the page in Light and 7.06:1 in Dark.
- After an action, focus stays on the button unless the action moves the user (e.g. opens a dialog, which then takes focus).
- Never hidden behind sticky headers or footers (2.4.11).

- **Not color-only:** destructive buttons say what they do ("Delete project"). The red reinforces the label; it doesn't replace it.
- **Target size:** every size is at least 32px tall and 50px wide, so all pass 2.5.8 (24×24).
- **Disabled** labels are exempt from contrast requirements (1.4.3).
- **Motion:** fill, label/icon colour, border and hover halo fade over `--button-duration` (→ `duration/fast`, 150ms) with `--button-easing` (→ `easing/ease-out`) — the same timing as the Figma prototype (hover and press: Smart Animate 150ms ease-out). The focus ring snaps on with no transition; the loading width never animates.
- **Reduced motion:** colour fades only — nothing moves, so nothing changes. The loading Spinner keeps rotating but slows to 1500ms (see Spinner).

## Usage guidelines

**Do**
- Use one primary button per area. Put secondary actions beside it.
- Start labels with a verb and keep them short: "Save", "Add user", "Delete project".
- Keep the button where it is while loading. The fixed 120px loading width does this for you.

**Don't**
- Don't use a button to navigate to another page. Use a link.
- Don't disable a submit button to signal errors. Let the user submit, then show what's wrong.
- Don't put two destructive buttons side by side.

## Content guidelines

- Labels: sentence case, a verb first, no trailing punctuation.
- Avoid vague labels ("OK", "Click here"). Say what will happen.
- Destructive actions name the object: "Delete invoice", not "Delete".
