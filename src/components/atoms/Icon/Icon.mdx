# Icon

One glyph from the **TrinityIcons** font (Default) or **TrinityBrandIcons** (Brand). Figma: *Icon* `60882:389`, 4 sizes × 2 fonts.

<InfoCallout>Accessibility pattern: <b>layout-content</b> (Storybook A11y Library). Target: WCAG 2.2 AA.</InfoCallout>

## Dependencies

None. One text layer with a private-use glyph (e.g. <Code>U+E4D9</Code>).

## Accessibility

- **Decorative by default:** `aria-hidden="true"`. Most icons sit next to text that already says the same thing.
- **Meaningful icons:** pass `label`. The icon then gets `role="img"` and that name. Use this only when the icon is the only way the meaning is shown.
- **Icon-only buttons:** don't label the icon; put `aria-label` on the button.
- **Contrast:** `--icon-default` is 15.61:1 (Light) / 21:1 (Dark) against the page. Meaningful icons need ≥ 3:1 (1.4.11).
- **Icon fonts and forced colors:** glyphs follow the text color, so they stay visible in Windows High Contrast. If the font fails to load, a meaningful icon still has its `label`.
