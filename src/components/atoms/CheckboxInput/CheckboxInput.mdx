# _checkboxInput

The drawn checkbox square: 24×24 touch area, 16×16 box, check or dash. It's the **private base of Checkbox**: it has no behavior and no accessible role of its own. Figma: *_checkboxInput* `30515:78570`, 12 authored variants.

<InfoCallout>Don't use this on its own in product UI. Use <b>Checkbox</b>, which wraps it around a real input. Accessibility pattern: <b>choice-controls</b>.</InfoCallout>

## Dependencies

None. Raw layers only (touchpoint → inputContainer → input → check / indeterminate).

## Accessibility

- Always `aria-hidden="true"`. The parent **Checkbox** supplies the native input, name, state and keyboard.
- Hover and focus here are only *looks*; Checkbox drives them from real pointer and keyboard events.
- Contrast is documented on **Checkbox** (border 15.61:1, check on fill 16.44:1).
