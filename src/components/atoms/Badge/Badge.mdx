# Badge

A small, static label for a count, a short status word, a dot, or an icon. It isn't interactive. Figma: *Badge* `7477:297479`, 23 authored variants.

<InfoCallout>Accessibility pattern: <b>feedback-status</b> (Storybook A11y Library). Target: WCAG 2.2 AA.</InfoCallout>

## Token Reference

<TokenTable prefixes={['badge/']} />

**Type** changes the shape: Default = pill (16px radius), Data = 2px radius, Icon = 16px radius.

## Visual States

These are meanings, not interaction states. Badges have no hover or focus.

## Dependencies

- **u-database** icon (instance swap "Icon"), recolored to the badge text color.

## When to use

- A count on a nav item or tab ("12").
- A short status next to an item ("NEW", "Error").
- A dot for "something changed here", next to a label that says what.

## When not to use

## Accessibility

**Built in**
- Plain `<span>`: no role and no live region (static badges must not announce themselves).
- Number / text badges: the visible text is what screen readers read.
- Dot and icon badges: include visually hidden text from `label`, because their meaning is visual only.

### Keyboard

None. Badges aren't focusable.

<ReviewCallout><b>Dots in Light mode:</b> the Default (yellow #e3f200) and Alternate (blue #41a8f2) dots are 1.06:1 and 2.22:1 against the page, and the dot ring is 2.54:1. That's fine <b>only if</b> the dot's meaning is also given in text (the <Code>label</Code> and the label next to it). A dot that's the only signal would need ≥ 3:1 (1.4.11).</ReviewCallout>

- **Not color-only:** Error badges carry a word or count. Don't rely on red alone.
- Outline and Alternate backgrounds stay light in Dark mode (as authored), so text contrast is the same in both modes.

- **Motion:** none — Badge has no states that change, so it has no motion tokens.

## Usage guidelines

**Do**
- Keep text short: a number or one word.
- Cap large counts ("99+").

**Don't**
- Don't make a badge clickable.
- Don't stack several badges on one item.

## Content guidelines

- Uppercase short words are fine ("NEW"). Avoid sentences.
- Counts: use digits, cap at "99+".
