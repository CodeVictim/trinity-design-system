# Radio Button Input

The drawn radio circle: 24×24 touch area, 20px container, 16px circle. It's the **base of Radio Button Field**: it has no behavior and no accessible role of its own. Figma: *Radio Button Input* `30173:78572`, 8 authored variants.

<InfoCallout>Don't use this on its own in product UI. Use <b>Radio Button Field</b>, which wraps it around a real radio input. Accessibility pattern: <b>choice-controls</b>.</InfoCallout>

## Dependencies

None. Raw layers only (touchpoint → inputContainer → input).

**Motion:** none of its own. This atom only defines the look; the **Radio Button Field** molecule animates its hover fill and selected ring (`--radiobutton-duration` / `--radiobutton-easing`).

## Accessibility

- Always `aria-hidden="true"`. The parent **Radio Button Field** supplies the native radio input, name, state and keyboard.
- Hover and focus here are only *looks*; Radio Button Field drives them from real pointer and keyboard events.
- Contrast is documented on **Radio Button Field** (circle 15.61:1 Light / 21:1 Dark).
