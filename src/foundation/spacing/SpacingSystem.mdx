# Spacing System

Trinity's spacing scale uses a **tiered naming convention** organized by size category — micro, small, medium, large. All values are pixels. Components never use spacing primitives directly; their **Layout** tokens alias them.

<CodeBlock>{`Primitives          Raw values:  --spacing-micro-100 (4px), --spacing-medium-800 (32px)
    └── Layout tokens   Component-scoped:  --button-padding, --checkbox-width, --card-radius`}</CodeBlock>

## Spacing Scale

<SimpleTable head={['Tier', 'Range', 'Use for', 'Steps']} rows={[
  ['Micro', '0–8px', 'Gaps inside a control: icon ↔ label, borders, hairlines', sp.filter(t => t.group === 'spacing/micro').length],
  ['Small', '10–16px', 'Padding inside controls; gaps between related items', sp.filter(t => t.group === 'spacing/small').length],
  ['Medium', '18–38px', 'Padding in cards and panels; gaps between groups', sp.filter(t => t.group === 'spacing/medium').length],
  ['Large', '40–64px', 'Section spacing, gutters, control heights', sp.filter(t => t.group === 'spacing/large' && t.value <= 64).length],
]} />

See **Spacing Scale**, **Border Radius** and **Opacity** for every value.

## Opacity

Figma stores opacity as 0–100; the CSS tokens are 0–1 (`opacity/040` → `--opacity-040: 0.4`).
