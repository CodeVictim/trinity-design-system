# Motion System

Trinity's motion lives in its own Figma collection, **Motion** — not in Primitives or Layout, because motion isn't layout. It has one mode (motion doesn't change between light and dark) and two tiers, the same shape as the rest of the system: a small **scale** of raw values, and **component groups** that alias it.

<CodeBlock>{`Motion collection
  Scale           duration/fast = 150 (ms)     →  --duration-fast: 150ms
                  easing/ease-out = "ease-out"  →  --easing-ease-out: ease-out
    └── Component groups (aliases)
                  button/duration → duration/fast   →  --button-duration: var(--duration-fast)
                  spinner/reduced/duration → duration/sustained`}</CodeBlock>

## How it's stored

- **Durations** are Figma number variables holding whole **milliseconds** → exported with `ms` (never `px`).
- **Easings** are Figma string variables holding a CSS keyword → exported **unquoted**.
- **Scopes are off** on every motion variable, so they never show up in Figma's property pickers.
- **Figma can't bind variables to prototype transitions.** The prototype reactions on each component set were set by hand to match these tokens (2026-10-19), and each component's description says so. If a token changes, its reactions need updating too.

## Rules

<SimpleTable head={['Rule', 'Why']} rows={[
  ['Use the component’s own motion token, never the scale directly', 'Retuning one component then never affects another'],
  ['Name the properties that change — never transition: all', '“all” also animates the focus ring and layout changes'],
  ['Focus rings snap on — transition: none', 'Keyboard users move fast; a fading ring lags (WCAG 2.4.7)'],
  ['Every animating component has its own reduced-motion block', 'Reduce, don’t remove — see Reduced Motion'],
  ['Nothing flashes more than 3 times a second', 'WCAG 2.3.1'],
  ['ease-out for entering and hover; ease-in for leaving', 'Things arrive quickly and settle; they leave without lingering'],
]} />
