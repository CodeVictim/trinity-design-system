# Type System

Trinity sets all text in **ABC Repro**, with two icon fonts (**TrinityIcons**, **TrinityBrandIcons**). Type is applied through **text-style classes** that map 1:1 to Figma text styles; the classes are built on typography primitives.

<CodeBlock>{`Primitives        font-family · font-size · font-weight · line-height · letter-spacing
    └── Text styles   .text-heading-lg · .text-body-sm · .text-data-md …   (Figma text styles)
            └── Component   applies a text style through its own tokens`}</CodeBlock>
